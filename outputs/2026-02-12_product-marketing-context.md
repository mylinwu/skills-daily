# Product Marketing Context 技能分析报告

> 来源：[product-marketing-context](https://skills.sh/coreyhaines31/marketingskills/product-marketing-context) | 安装量：1,967

## 技能用途

这是一个**产品营销上下文文档生成器**，帮助用户创建和维护一份结构化的产品营销基础信息文档（`.claude/product-marketing-context.md`）。该文档作为其他营销技能（如 content-strategy、copywriting 等）的共享上下文，避免每次使用营销技能时重复提供基础信息。

**核心能力：**

- **自动从代码库提取**：扫描 README、落地页、营销文案、package.json 等文件，自动生成产品营销上下文初稿
- **交互式信息收集**：通过逐节对话的方式，引导用户填写 12 个关键营销维度
- **增量更新**：检测已有文档，仅更新需要修改的部分
- **跨技能共享**：生成的文档被其他营销技能自动引用，形成统一的信息源

**典型使用场景：**

1. 新项目初始化时，一次性建立产品营销基础信息
2. 产品定位调整后，更新核心信息文档
3. 为团队中的 AI 营销工具链提供统一的产品上下文

## 作用机制分析

### 1. 智能初始化策略

技能设计了两条路径来创建上下文文档：

- **路径A（推荐）**：自动从代码库提取信息，生成初稿后让用户修正补充。这大幅降低了用户的输入负担
- **路径B**：从零开始，逐节对话收集信息

同时支持增量更新——如果文档已存在，只询问需要修改的部分。这个设计避免了重复劳动。

### 2. 12维营销信息框架

技能定义了 12 个结构化信息维度，覆盖了产品营销的完整知识图谱：

| 维度 | 核心问题 |
|------|----------|
| 产品概述 | 你是什么？在哪个品类？ |
| 目标受众 | 卖给谁？他们"雇佣"你做什么？ |
| 用户画像 | B2B 场景下的多角色决策链 |
| 痛点问题 | 客户在找到你之前面临什么困境？ |
| 竞争格局 | 直接/间接/替代竞品分别是谁？ |
| 差异化 | 你有什么别人没有的？ |
| 异议处理 | 销售中最常见的反对意见 |
| 转换动力学 | JTBD 四力模型（推力/拉力/惯性/焦虑） |
| 客户语言 | 客户原话怎么描述问题和方案 |
| 品牌声音 | 语调、风格、个性 |
| 证据支撑 | 数据、客户案例、推荐语 |
| 目标 | 商业目标和关键转化动作 |

### 3. JTBD 四力模型的巧妙应用

技能在"转换动力学"部分引入了 Jobs To Be Done 的四力分析框架：

- **Push（推力）**：当前方案的不满驱动用户离开
- **Pull（拉力）**：你的产品吸引用户过来
- **Habit（惯性）**：让用户留在旧方案的习惯力量
- **Anxiety（焦虑）**：切换到新方案的担忧

这个框架帮助用户系统性地理解客户的决策心理，而不仅仅是列出功能优势。

### 4. 标准化文档模板

技能内置了完整的 Markdown 文档模板，包含所有 12 个维度的字段定义。这确保了：

- 输出格式一致，便于其他技能解析
- 用户可以直接在模板上填写，降低认知负担
- 表格格式用于结构化数据（画像、异议、术语表等）

### 5. 营销技能生态的枢纽角色

这个技能的核心价值不在于自身，而在于它作为**信息枢纽**的定位。它生成的 `.claude/product-marketing-context.md` 文件被整个营销技能链引用——content-strategy 在规划前会检查这个文件，copywriting 在写作时会参考品牌声音和客户语言。

这种设计模式类似于软件工程中的"配置文件"概念：一次写入，多处引用。

### 总结

Product Marketing Context 是一个**基础设施型技能**，通过结构化的信息收集流程和标准化的文档输出，为整个营销技能生态提供统一的产品上下文。它的设计亮点在于"自动提取 + 人工修正"的初始化策略、JTBD 四力模型的引入，以及作为跨技能共享上下文的枢纽定位。对于需要频繁使用 AI 辅助营销的团队来说，这是一个值得优先配置的基础技能。
