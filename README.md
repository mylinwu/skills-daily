## 📖 项目简介

**Skills Daily** 是一个专注于分析 [Skills.sh](https://skills.sh) 平台热门技能的自动化项目。每天，我们从海量技能中筛选出最受关注的工具，进行深度解析并生成结构化报告。

### 核心问题解答

| 问题 | 答案 |
|------|------|
| **这个技能有什么用？** | 完整的功能定位与适用场景分析 |
| **应该怎么用？** | 实际使用方法、命令、最佳实践 |
| **为什么值得关注？** | 设计机制、工作原理、核心优势深度解读 |

---

## 📂 报告文件

本项目将生成的分析报告开源分享，位于 [`outputs/技能分析/`](./outputs/技能分析/) 

---

## 🎯 报告特色

每份报告包含以下维度分析：

### 1️⃣ 技能用途

- 功能定位与核心价值
- 适用场景与解决的问题
- 典型使用案例

### 2️⃣ 目录结构

- 技能的文件组织方式
- 各文件/模块的作用
- 整体架构概览

### 3️⃣ 作用机制深度分析

- 提示词引导机制
- 脚本/工具工作原理
- 方法论与最佳实践
- 代码示例与关键模式
